实测发现

三个官方文档没写清楚、但直接决定你省不省得到钱的坑

这三点是开发过程中真踩到的。不解决它们，"有券"就永远变不成"省钱"。

FINDING 01

可领券不能直接用来下单

available-coupons 只返回券名和图片，没有 couponId / couponCode，拿去试算会被服务端拒绝。
→ 必须先 auto-bind-coupons 领进券包，再从券包取带 ID 的券对象。
FINDING 02

券包里的券 ≠ 这个门店能用

query-my-coupons 不做门店和渠道校验，只说明"你拥有它"。实测券包 5 张，指定门店到店场景只有 1 张真能用。
→ 必须用 query-store-coupons 校验。这是"有券却用不掉"的根本原因。
FINDING 03

券可能"未到使用时间"，只有标签会告诉你

实测 3 张券的生效日期是次日 / 下周，instructions.labels 明确写着"未到使用时间"。只看有效期会误判。
→ 必须读 labels[].text，不能只看起止日期。

过期优先级快过期的积分优先花掉 —— 归零的价值是 0
活动择时结合活动日历判断「现在买还是再等等」
